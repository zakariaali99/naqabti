# Global Workspace Agent Guidelines

## 🛑 Strict Rule: Mandatory Plan Approval & Stop Mechanism

1. **Stop Immediately After Creating a Plan**:
   - Whenever an implementation plan is created or requested, you MUST STOP immediately after creating/updating `implementation_plan.md`.
   - Do NOT proceed to implementation or start writing feature code within the same turn.

2. **No Code Changes or Migrations Without Explicit Approval**:
   - Under no circumstances should source code be modified, new feature files created, or database migrations applied until the USER explicitly replies and confirms approval (e.g., "Approved", "Proceed", "ابدأ التنفيذ", "نفذ", or "Go ahead").

3. **Strict Step Separation**:
   - Planning and Execution are strictly two separate phases. Never combine them or assume approval.
